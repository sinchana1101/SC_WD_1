# Simple Web Project

A clean and interactive frontend web application built using HTML, CSS, and JavaScript.

## Features
* Responsive UI layout using custom CSS styling.
* Dynamic client-side behavior implemented with vanilla JavaScript.
* Clean, semantic HTML structure.

## Tech Stack
* **HTML5** - Structure
* **CSS3** - Styling & Layout
* **JavaScript (ES6+)** - Interactivity & Logic

## How to Run Locally
1. Download or clone this repository.
2. Open the `index.html` file directly in any modern web browser (Chrome, Safari, Edge, Firefox).
